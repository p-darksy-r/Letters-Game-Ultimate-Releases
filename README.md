# Letters Game Ultimate Releases

Public Windows distribution channel for **Letters Game Ultimate**.

- `update-manifest.json` identifies the current application build and its SHA-256.
- GitHub Releases contain `Letters-Game-Ultimate.exe` and the matching `update.exe` bootstrapper.
- Application source code is maintained separately in a private repository.

## Pre-release notice

Versions below `v1.0.0` are Windows development builds and are not Steam releases. Current executables are not yet Authenticode-signed and may trigger Windows security warnings or organizational application-control policies.
